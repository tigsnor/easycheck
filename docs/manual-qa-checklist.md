# PlateNote 수동 QA 체크리스트

이 문서는 개발자 테스트 가능도를 100%에 가깝게 만들기 위한 기본 수동 검증 절차입니다.

## 사전 준비

```bash
scripts/bootstrap_flutter.sh
export PATH="$PWD/.tool/flutter/bin:$PATH"
flutter pub get
flutter devices
flutter run
```

## 0. 실제 기기/시뮬레이터 실행 확인

- [ ] GitHub Actions의 품질 검사, Android APK 빌드, iOS Simulator 빌드가 모두 성공한다.
- [ ] Actions artifact에서 Android APK 또는 iOS Simulator 앱을 다운로드할 수 있다.
- [ ] 테스트한 앱 버전, Actions run number, 기기와 OS 버전을 기록한다.
- [ ] `flutter devices`에서 iPhone Simulator, Android Emulator 또는 실제 기기가 표시된다.
- [ ] `flutter run -d <device-id>`로 앱이 실행된다.
- [ ] 앱을 종료 후 다시 실행해도 첫 화면이 정상 표시된다.

## 1. 실험 노트 기본 흐름

- [ ] 앱이 실행되고 `실험 노트` 홈 화면이 보인다.
- [ ] `새 실험` 또는 `첫 실험 만들기`를 눌러 bottom sheet가 열린다.
- [ ] 제목, 실험 유형, 프로젝트, 메모를 입력하고 생성한다.
- [ ] 생성된 실험이 최근 실험 목록에 표시된다.
- [ ] 새 실험 생성 시 저장된 Plate 템플릿을 선택하면 실험과 Plate가 함께 생성된다.
- [ ] 템플릿의 기본 선택은 `빈 Plate로 시작`이다. 템플릿 없이 CCK-8·ELISA·Custom 실험의 Plate를 처음 열면 그룹·농도·결과가 비어 있고 예시 값이 저장되지 않는다.
- [ ] 기존 실험의 저장된 Plate 배치와 결과는 업데이트 후에도 그대로 유지된다.
- [ ] 실험 메뉴의 `설계 복제`에서 복사/초기화 범위를 안내하며 취소하면 새 실험이 생기지 않는다.
- [ ] 완료된 실험을 설계 복제하면 새 초안에 기본정보·단계 제목·자원·Plate 배치만 복사되고 결과·분석 제외·실험/Plate/well 메모·타이머·완료 시각·이력이 초기화된다.
- [ ] 복사본의 Plate를 홈과 실험 상세 양쪽에서 열어 같은 배치를 확인하고, 수정 후에도 원본이 유지되는지 확인한다.
- [ ] 개발용 복제 저장 실패 시 원본은 유지되고 새 복사본이 정리된다. 정리까지 실패하면 오류 메시지에 남은 복사본 가능성을 안내한다.
- [ ] 검색창에서 제목 또는 태그로 검색했을 때 결과가 필터링된다.
- [ ] 실험 카드를 눌러 상세 화면으로 이동한다.
- [ ] 제목/상태/메모를 수정하고 저장한다.
- [ ] 빈 실험 제목으로 저장하면 제목 입력란 아래 오류가 표시되고 다른 화면으로 지연 표시되지 않는다.
- [ ] 실험 노트에서 `저장되지 않은 변경` → `저장 중…` → `저장됨 HH:mm` 상태가 순서대로 표시된다.
- [ ] 실험 저장 실패 시 화면에 `저장 실패`와 `다시 시도`가 유지되고 재시도 후 저장 완료 상태로 바뀐다.
- [ ] 저장하지 않은 상태에서 뒤로가면 계속 편집, 저장하지 않고 나가기, 저장 후 나가기를 선택할 수 있다.
- [ ] 앱을 재시작해도 실험 노트가 유지된다.
- [ ] 실험 목록에서 아래로 당기면 저장소의 최신 내용으로 새로고침된다.
- [ ] 실험 목록을 불러오지 못하면 데이터 보존 안내와 `다시 시도` 버튼이 표시되고 재시도 후 목록이 복구된다.
- [ ] Plate 로드 실패 시 화면 안에 데이터 보존 안내와 `다시 시도`가 표시되고 재시도 후 grid가 복구된다.
- [ ] 기존 형식의 실험/Plate 데이터가 업데이트 후에도 열리고 다음 저장 후 versioned 형식으로 유지된다.
- [ ] 개발용 손상 파일 시나리오에서 직전 정상본이 복구되고 앱이 핵심 데이터를 다시 표시한다.
- [ ] 자동 복구 직후 `로컬 데이터 복구 완료` 안내가 나타나며 확인 전에는 임의로 닫히지 않는다.
- [ ] 실험 삭제 시 확인 창이 나타나고 `취소`를 누르면 데이터가 유지된다.
- [ ] 삭제를 확정하면 실험과 연결 Plate가 사라지고, SnackBar의 `실행 취소`로 모두 복원된다.
- [ ] 상단 `전체 데이터 백업 및 복원`에서 실험·Plate·사용자 템플릿이 포함된 v2 JSON을 복사하거나 `.json` 파일로 공유한다.
- [ ] `백업 파일 선택`으로 Files/iCloud의 JSON을 읽거나 직접 붙여넣으면 실험/Plate 개수와 오류 여부가 표시된다.
- [ ] 개발용 저장 실패 시나리오에서 일부 데이터만 남지 않고 복원 시작 전 실험/Plate 상태로 되돌아간다.
- [ ] 병합 복원 확인 후 기존 데이터는 유지되고 같은 ID는 덮어쓰며 새 실험과 Plate가 추가된다.
- [ ] v1 백업을 복원해도 기존 사용자 템플릿은 유지된다.
- [ ] 손상된 로컬 파일 때문에 새 백업을 만들 수 없어도 파일 선택과 전체 복구가 가능하다.
- [ ] 전체 복구 확인에서 백업에 없는 실험이 목록에서 제외됨을 안내하며, 취소하면 데이터가 바뀌지 않는다.
- [ ] 전체 복구 후 앱을 다시 시작해도 새 실험·Plate·템플릿을 불러오고 이후 변경을 저장할 수 있다.
- [ ] 복구 준비 또는 전환 실패 시 이전 데이터가 유지되고, 남은 준비 파일이 다음 시작에서 자동 적용되지 않는다.

## 2. Plate 기본 흐름

- [ ] 현재 Plate를 이름을 지정해 템플릿으로 저장할 수 있다.
- [ ] 다른 Plate 설정 후 저장한 템플릿을 적용하면 그룹·농도·역할·부피가 복원된다.
- [ ] 템플릿 적용 시 이전 측정 결과와 분석 제외 상태는 복사되지 않는다.
- [ ] 템플릿 적용 확인에서 취소하면 현재 Plate가 유지된다.
- [ ] 저장된 Plate 템플릿 관리에서 이름 변경과 삭제가 동작한다.
- [ ] 저장된 템플릿이 없어도 기본 CCK-8 예시 템플릿을 적용할 수 있다.

- [ ] 실험 카드 또는 상세 화면에서 `Plate 열기`를 눌러 plate editor로 이동한다.
- [ ] 96-well plate와 A-H/1-12 헤더가 보인다.
- [ ] 상단에는 Plate 이름·저장 상태·실행 취소·더보기만 표시되고 작은 화면에서도 겹치지 않는다.
- [ ] well 선택 전에는 하단에 결과 연속 입력·일괄 입력·희석 적용이, 선택 후에는 편집·그룹·범위·희석·선택 해제가 표시된다. 단일 선택 시 연속 입력도 사용할 수 있다.
- [ ] 전체 내보내기, 변경 이력, 템플릿 작업은 상단 `더보기`에서 실행할 수 있다.
- [ ] 기본 Plate 화면은 grid 중심으로 표시되고 `요약 보기`를 누르면 Plate 요약과 준비 점검이 바텀시트로 열린다.
- [ ] 단일 well 선택 후 하단에 좌표가 표시되고 `상세`를 누르면 well 정보가 열린다. 행·열·범위 선택 시 시작/끝 좌표와 개수가 표시된다.
- [ ] 상단 `Plate 분석 보기`는 선택 전·후 모두 분석 바텀시트를 연다. 선택 중에도 더보기의 `결과 일괄 입력`으로 이동할 수 있다.
- [ ] 기본 작업 보기에서 well이 48dp 이상이며 확대 시 글자도 커진다. 전체 보기에는 확대 후 선택하라는 안내가 보인다.
- [ ] `결과` 보기에서 실제 0 값, 미입력, 빈 well, 분석 제외 ×를 구분할 수 있다. 미입력 개수는 배치된 well 중 제외되지 않은 항목만 센다.
- [ ] 배치/결과 보기 전환은 측정값·선택 좌표를 변경하거나 저장하지 않는다. 화면 숫자가 반올림되어도 상세에는 원래 값과 단위가 표시된다.
- [ ] 320px 화면과 큰 글자에서 보기 전환·확대·좌우 스크롤을 사용할 수 있다.
- [ ] 완료된 실험의 Plate에서도 분석과 분석 TSV 복사·공유가 가능하며 편집·희석·결과 입력은 잠겨 있다.
- [ ] `Plate 확대`를 누르면 기본 48dp에서 56/64/72/80dp로 커지고 좌우 스크롤로 12열을 확인할 수 있다. 큰 글자 설정에서는 칸도 함께 커진다.
- [ ] `Plate 축소`와 `Plate 전체 보기`가 동작하며 확대 전 선택한 행·열·well이 유지된다.
- [ ] 작은 화면과 가로 방향에서도 확대/축소 버튼이 잘리거나 겹치지 않는다.
- [ ] 새 Plate는 빈 96-well로 시작한다. 예시 배치는 템플릿을 명시적으로 선택·적용한 경우에만 나타난다.
- [ ] `희석 계산 적용`에서 시작 농도, 희석 배수, 단계 수, 반복 well 수, 방향을 바꿔 plate에 적용한다.
- [ ] `0 농도 control 포함`을 켜면 대조군 역할 선택 전 적용이 차단된다. 역할을 고르면 마지막 0 농도 well에만 저장되고 재실행 후에도 유지된다.
- [ ] 같은 그룹에 처리군과 대조군이 있으면 분석표·분석 TSV에서 실제 well 역할로 구분된다. Blank는 배경 보정, Vehicle/Untreated/Negative는 해당 기준에 따라 정규화에 사용된다.
- [ ] Stock 농도, well당 최종 부피, 여유분을 바꾸면 농도별 stock/희석액 master mix 미리보기가 즉시 갱신된다.
- [ ] 1 µL 미만 stock 분주에는 중간 희석액 검토 경고가 표시된다.
- [ ] 선택한 well 수가 필요한 well 수보다 적으면 희석 적용이 차단되고 필요한 개수가 안내된다.
- [ ] 희석 입력 오류와 well 부족 오류는 희석 바텀시트 안의 오류 패널에 즉시 표시된다.
- [ ] 그룹명이 비어 있으면 그룹명 입력란 아래에 오류가 표시된다.
- [ ] 희석 적용 후 대상 well에 최종 부피와 부피 단위가 저장되고 Plate TSV에도 포함된다.
- [ ] 단일 well을 탭하면 상세 카드가 해당 well로 바뀐다.
- [ ] 행 헤더 `A`를 탭하면 12개 well이 선택된다.
- [ ] 열 헤더 `1`을 탭하면 8개 well이 선택된다.
- [ ] well을 길게 누른 채 드래그하면 시작 well부터 현재 위치까지 사각형이 실시간으로 선택되고, 손을 떼면 유지된다. 이전 선택 위치가 새 드래그의 시작점에 영향을 주지 않는다.
- [ ] 상단 또는 하단의 `드래그 선택`을 켜면 길게 누르지 않고 바로 드래그할 수 있고, 끄면 일반 밀기 스크롤이 동작한다.
- [ ] A1→C3과 C3→A1 모두 9개가 선택되고 도중에 B2로 되돌리면 범위가 줄어든다. 선택 범위에 그룹·희석 적용이 가능하다.
- [ ] 좁은 화면에서 가장자리에 손가락을 두면 가로·세로로 자동 스크롤되며 H12까지 선택할 수 있다. 손을 떼거나 터치가 취소되면 자동 스크롤이 멈춘다.
- [ ] 확대·전체 보기·큰 글자·스크롤 후에도 선택 좌표가 맞고, 화면 읽기 기능의 단일 선택·범위 선택을 사용할 수 있다.
- [ ] 선택 영역에 `그룹 지정`을 눌러 그룹명, 라벨, 색상, 역할, 단위를 입력한다.
- [ ] 지정한 그룹 색상과 라벨이 plate에 표시된다.
- [ ] `실험 준비 점검`에서 Blank/Control 누락, 반복 well 부족, 농도 단위 혼용 경고를 확인한다.
- [ ] 필요한 Blank와 Control 및 반복 well을 추가하면 해당 경고가 사라진다.
- [ ] `결과 일괄 입력`에서 Excel의 A-H × 1-12 행렬을 붙여넣고 인식된 숫자 개수와 오류를 확인한다.
- [ ] 하단 또는 더보기의 `결과 연속 입력`은 선택 좌표(선택 없으면 A1)에서 시작하고 선택 범위 밖의 well도 포함됨을 안내한다.
- [ ] 행 방향 A12 → B1, 열 방향 H1 → A2 이동을 확인하고 H12 저장 후 창이 닫히는지 확인한다.
- [ ] 기존 값·단위·분석 제외 안내가 보이고 새 값 저장 후에도 농도·역할·메모·제외 상태가 유지된다.
- [ ] 저장 실패 시 현재 좌표와 입력이 유지되고 수정 후 재시도할 수 있다. 저장 중 중복 저장·닫기·뒤로가기가 차단된다.
- [ ] 미저장 입력으로 뒤로가기/닫기 시 계속 입력·폐기를 선택할 수 있고 앞서 저장한 well은 유지된다.
- [ ] 320px 화면·큰 글자·키보드 표시 상태에서 다음 좌표와 저장 버튼에 접근할 수 있다. 실제 키보드에서 음수·지수 입력 가능 여부도 확인한다.
- [ ] 연속 입력 저장 내역과 실행 취소를 확인하고, 완료된 실험에서는 연속 입력 메뉴가 나타나지 않는다.
- [ ] `결과 일괄 입력`에서 CSV/TSV/TXT 파일을 선택하면 파일 내용이 preview에 반영된다.
- [ ] `결과 일괄 입력`에서 결과 단위와 측정 파장을 확인·수정하면 적용 단위가 갱신된다.
- [ ] `전체 96개 well 비교`에서 A1/A12/H1/H12 좌표와 신규·덮어쓰기·동일·유지 상태를 확인한다. 선택한 well의 정확한 기존값·적용 후 값·단위가 하단에 보인다.
- [ ] `값 비교 목록`에서 전체 well을 확인하고 `바뀌는 well만 보기`로 신규·덮어쓰기 항목만 볼 수 있다. 숫자가 같아도 단위가 다르면 덮어쓰기로 표시된다.
- [ ] 빈 셀과 입력 범위 밖의 well은 기존 값·단위를 유지하고 0은 실제 입력값으로 표시된다. 분석 제외 상태와 메모는 유지된다.
- [ ] 행 좌표 없는 입력은 A1부터, 행 좌표 있는 입력은 원본 좌표에 적용된다고 안내한다. Plate의 현재 선택 영역에 따라 가져오기 좌표가 바뀌지 않는다.
- [ ] 미리보기를 닫거나 덮어쓰기를 취소해도 저장되지 않는다. 입력값·단위 수정 후 다시 열면 새 비교 결과가 보인다.
- [ ] 숫자가 아닌 값 또는 모호한 첫 행이 있으면 전체 미리보기·적용이 비활성화되며, 오류/첫 행 해석을 해결하면 활성화된다.
- [ ] 320px·큰 글자에서 미리보기 가로/세로 스크롤로 H12까지 이동하고 선택 값과 닫기 버튼을 확인할 수 있다.
- [ ] 일괄 결과를 적용하면 A1-H12 좌표에 결과값과 결과 단위가 저장된다.
- [ ] 결과 적용 후 Plate 요약에 최근 결과 가져오기 source 이름, 개수, 단위가 표시된다.
- [ ] 기존 결과가 있는 좌표를 다시 붙여넣거나 같은 파일을 다시 선택하면 덮어쓰기/중복 import 확인 창이 표시된다.
- [ ] 선택한 well의 농도와 결과값/결과 단위(예: `0.82 OD450`)를 편집하고 저장한다.
- [ ] Well 메모를 입력하고 이상치 또는 실험 오류가 있는 well을 `분석에서 제외`로 표시한다.
- [ ] 저장 후 상세 카드에 측정 결과, 메모, `분석 제외` 상태가 표시된다.
- [ ] `기본 결과 분석`에서 같은 그룹·농도·결과 단위의 반복 well이 하나의 행으로 묶인다.
- [ ] 평균, 표본 표준편차(SD), CV, blank 보정값과 control 대비 비율이 수동 계산과 일치한다.
- [ ] `분석에서 제외`한 well은 평균에서 빠지고 제외 개수와 well 번호가 표시된다.
- [ ] Blank 또는 control이 없으면 보정·정규화 기준이 없다는 문구가 표시되고 raw 평균은 유지된다.
- [ ] 농도가 지정된 Treatment/Sample/Standard 결과가 농도 오름차순 차트로 표시된다.
- [ ] Control이 있으면 차트가 control 대비 비율을, 없으면 blank 보정 결과를 표시한다.
- [ ] `분석 TSV 복사`와 `분석 파일 공유`로 reference, 포함/제외 well, 평균, SD, CV, 정규화값을 내보낼 수 있다.
- [ ] `Plate 내보내기`를 열고 TSV에 결과값, 결과 단위, 분석 제외 여부, 메모가 포함되며 `복사하기`와 `.tsv` 파일 공유를 사용할 수 있다.
- [ ] Plate 변경 중 `저장 중…`, 완료 후 `저장됨 HH:mm` 상태가 표시된다.
- [ ] Plate 저장 실패 시 기존 Plate가 유지되고 `저장 실패`의 `다시 시도`로 동일한 변경을 다시 저장할 수 있다.
- [ ] 그룹 지정, 희석 적용, 결과 입력 후 상단 실행 취소 또는 SnackBar `실행 취소`로 직전 Plate 상태를 복원한다.
- [ ] 앱을 재시작해도 plate layout과 그룹 정보가 유지된다.
