# EasyCheck 수동 QA 체크리스트

이 문서는 개발자 테스트 가능도를 100%에 가깝게 만들기 위한 기본 수동 검증 절차입니다.

## 사전 준비

```bash
scripts/bootstrap_flutter.sh
export PATH="$PWD/.tool/flutter/bin:$PATH"
flutter pub get
flutter devices
flutter run
```

## 0. 실제 기기/시뮬레이터 실행 확인

- [ ] GitHub Actions의 품질 검사, Android APK 빌드, iOS Simulator 빌드가 모두 성공한다.
- [ ] Actions artifact에서 Android APK 또는 iOS Simulator 앱을 다운로드할 수 있다.
- [ ] 테스트한 앱 버전, Actions run number, 기기와 OS 버전을 기록한다.
- [ ] `flutter devices`에서 iPhone Simulator, Android Emulator 또는 실제 기기가 표시된다.
- [ ] `flutter run -d <device-id>`로 앱이 실행된다.
- [ ] 앱을 종료 후 다시 실행해도 첫 화면이 정상 표시된다.

## 1. 실험 노트 기본 흐름

- [ ] 앱이 실행되고 `실험 노트` 홈 화면이 보인다.
- [ ] `새 실험` 또는 `첫 실험 만들기`를 눌러 bottom sheet가 열린다.
- [ ] 제목, 실험 유형, 프로젝트, 메모를 입력하고 생성한다.
- [ ] 생성된 실험이 최근 실험 목록에 표시된다.
- [ ] 새 실험 생성 시 저장된 Plate 템플릿을 선택하면 실험과 Plate가 함께 생성된다.
- [ ] 템플릿을 사용하지 않으면 기존 기본 Plate 흐름을 그대로 사용할 수 있다.
- [ ] 검색창에서 제목 또는 태그로 검색했을 때 결과가 필터링된다.
- [ ] 실험 카드를 눌러 상세 화면으로 이동한다.
- [ ] 제목/상태/메모를 수정하고 저장한다.
- [ ] 앱을 재시작해도 실험 노트가 유지된다.
- [ ] 기존 형식의 실험/Plate 데이터가 업데이트 후에도 열리고 다음 저장 후 versioned 형식으로 유지된다.
- [ ] 개발용 손상 파일 시나리오에서 직전 정상본이 복구되고 앱이 핵심 데이터를 다시 표시한다.
- [ ] 자동 복구 직후 `로컬 데이터 복구 완료` 안내가 나타나며 확인 전에는 임의로 닫히지 않는다.
- [ ] 실험 삭제 시 확인 창이 나타나고 `취소`를 누르면 데이터가 유지된다.
- [ ] 삭제를 확정하면 실험과 연결 Plate가 사라지고, SnackBar의 `실행 취소`로 모두 복원된다.
- [ ] 상단 `전체 데이터 백업 및 복원`에서 실험과 Plate가 포함된 JSON을 복사하거나 `.json` 파일로 공유한다.
- [ ] `백업 파일 선택`으로 Files/iCloud의 JSON을 읽거나 직접 붙여넣으면 실험/Plate 개수와 오류 여부가 표시된다.
- [ ] 개발용 저장 실패 시나리오에서 일부 데이터만 남지 않고 복원 시작 전 실험/Plate 상태로 되돌아간다.
- [ ] 병합 복원 확인 후 기존 데이터는 유지되고 같은 ID는 덮어쓰며 새 실험과 Plate가 추가된다.

## 2. Plate 기본 흐름

- [ ] 현재 Plate를 이름을 지정해 템플릿으로 저장할 수 있다.
- [ ] 다른 Plate 설정 후 저장한 템플릿을 적용하면 그룹·농도·역할·부피가 복원된다.
- [ ] 템플릿 적용 시 이전 측정 결과와 분석 제외 상태는 복사되지 않는다.
- [ ] 템플릿 적용 확인에서 취소하면 현재 Plate가 유지된다.
- [ ] 저장된 Plate 템플릿 관리에서 이름 변경과 삭제가 동작한다.
- [ ] 저장된 템플릿이 없어도 기본 CCK-8 예시 템플릿을 적용할 수 있다.

- [ ] 실험 카드 또는 상세 화면에서 `Plate 열기`를 눌러 plate editor로 이동한다.
- [ ] 96-well plate와 A-H/1-12 헤더가 보인다.
- [ ] `Plate 확대`를 누르면 well이 40/48/56/64px로 커지고 좌우 스크롤로 12열을 확인할 수 있다.
- [ ] `Plate 축소`와 `Plate 화면 맞춤`이 동작하며 확대 전 선택한 행·열·well이 유지된다.
- [ ] 작은 화면과 가로 방향에서도 확대/축소 버튼이 잘리거나 겹치지 않는다.
- [ ] 기본 A/B열에 `1000 → 500 → 250 → 125 → 62.5 → 31.25 → 0` 패턴이 보인다.
- [ ] `희석 계산 적용`에서 시작 농도, 희석 배수, 단계 수, 반복 well 수, 방향을 바꿔 plate에 적용한다.
- [ ] Stock 농도, well당 최종 부피, 여유분을 바꾸면 농도별 stock/희석액 master mix 미리보기가 즉시 갱신된다.
- [ ] 1 µL 미만 stock 분주에는 중간 희석액 검토 경고가 표시된다.
- [ ] 선택한 well 수가 필요한 well 수보다 적으면 희석 적용이 차단되고 필요한 개수가 안내된다.
- [ ] 희석 적용 후 대상 well에 최종 부피와 부피 단위가 저장되고 Plate TSV에도 포함된다.
- [ ] 단일 well을 탭하면 상세 카드가 해당 well로 바뀐다.
- [ ] 행 헤더 `A`를 탭하면 12개 well이 선택된다.
- [ ] 열 헤더 `1`을 탭하면 8개 well이 선택된다.
- [ ] `범위 시작` 후 다른 well을 탭하면 사각형 범위가 선택된다.
- [ ] 선택 영역에 `그룹 지정`을 눌러 그룹명, 라벨, 색상, 역할, 단위를 입력한다.
- [ ] 지정한 그룹 색상과 라벨이 plate에 표시된다.
- [ ] `실험 준비 점검`에서 Blank/Control 누락, 반복 well 부족, 농도 단위 혼용 경고를 확인한다.
- [ ] 필요한 Blank와 Control 및 반복 well을 추가하면 해당 경고가 사라진다.
- [ ] `결과 일괄 입력`에서 Excel의 A-H × 1-12 행렬을 붙여넣고 인식된 숫자 개수와 오류를 확인한다.
- [ ] `결과 일괄 입력`에서 CSV/TSV/TXT 파일을 선택하면 파일 내용이 preview에 반영된다.
- [ ] 일괄 결과를 적용하면 A1-H12 좌표에 결과값과 결과 단위가 저장된다.
- [ ] 기존 결과가 있는 좌표를 다시 붙여넣으면 덮어쓰기 개수가 표시된다.
- [ ] 선택한 well의 농도와 결과값/결과 단위(예: `0.82 OD450`)를 편집하고 저장한다.
- [ ] Well 메모를 입력하고 이상치 또는 실험 오류가 있는 well을 `분석에서 제외`로 표시한다.
- [ ] 저장 후 상세 카드에 측정 결과, 메모, `분석 제외` 상태가 표시된다.
- [ ] `기본 결과 분석`에서 같은 그룹·농도·결과 단위의 반복 well이 하나의 행으로 묶인다.
- [ ] 평균, 표본 표준편차(SD), CV, blank 보정값과 control 대비 비율이 수동 계산과 일치한다.
- [ ] `분석에서 제외`한 well은 평균에서 빠지고 제외 개수와 well 번호가 표시된다.
- [ ] Blank 또는 control이 없으면 보정·정규화 기준이 없다는 문구가 표시되고 raw 평균은 유지된다.
- [ ] 농도가 지정된 Treatment/Sample/Standard 결과가 농도 오름차순 차트로 표시된다.
- [ ] Control이 있으면 차트가 control 대비 비율을, 없으면 blank 보정 결과를 표시한다.
- [ ] `분석 TSV 복사`와 `분석 파일 공유`로 reference, 포함/제외 well, 평균, SD, CV, 정규화값을 내보낼 수 있다.
- [ ] `Plate 내보내기`를 열고 TSV에 결과값, 결과 단위, 분석 제외 여부, 메모가 포함되며 `복사하기`와 `.tsv` 파일 공유를 사용할 수 있다.
- [ ] Plate 변경 중 `저장 중…`, 완료 후 `저장됨 HH:mm` 상태가 표시된다.
- [ ] 그룹 지정, 희석 적용, 결과 입력 후 상단 실행 취소 또는 SnackBar `실행 취소`로 직전 Plate 상태를 복원한다.
- [ ] 앱을 재시작해도 plate layout과 그룹 정보가 유지된다.
