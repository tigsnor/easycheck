# 실험실 작업 관점의 UI·UX 점검

검토일: 2026-10-22. 실험 설계 → 장갑 착용 중 배치 확인 → Plate reader 결과 입력 → 누락 확인 → 완료 후 분석 흐름을 기준으로 검토했습니다. 코드·위젯 동작과 320px 화면/큰 글자 설정을 검증한 결과이며, 실제 연구원 인터뷰나 장갑 착용 실기기 테스트 결과는 아닙니다.

## 이번에 수정한 불편

| 불편 | 연구 작업에 미치는 영향 | 수정 |
|---|---|---|
| 휴대폰에 96-well 전체를 맞추면 칸이 대략 14–20dp로 작아짐 | 인접 well을 잘못 선택하기 쉬움 | 기본 작업 칸을 48dp로 설정하고 최대 80dp까지 확대. 전체 보기는 배치 확인용이라고 안내 |
| 확대해도 글자는 7–8로 고정 | 농도를 읽기 위해 계속 상세를 열어야 함 | 작업 보기에서 12–14 크기 글자 사용. 큰 글자 설정에 맞춰 칸도 확대 |
| 그룹/농도가 표시되면 좌표를 다시 행·열에서 찾아야 함 | 오른쪽으로 스크롤하거나 Plate와 휴대폰을 번갈아 볼 때 위치를 놓침 | 작업 보기의 모든 칸에 A1 같은 좌표 표시. 하단에 선택한 좌표/범위와 개수 표시 |
| 결과 입력 여부와 분석 제외가 grid에 드러나지 않음 | 누락 well이나 제외한 outlier를 다시 하나씩 열어야 함 | 배치/결과 보기 전환, 입력·미입력·제외 개수, 미입력 문구와 제외 × 표시 |
| well을 선택하면 결과 일괄 입력이 하단에서 사라짐 | 가져오기 전에 선택 해제를 해야 함 | 더보기 메뉴에서도 결과 일괄 입력에 접근. 완료된 실험은 계속 입력 잠금 |
| 행렬 입력 예시가 `\\t`, `\\n` 문자열로 보임 | 붙여넣을 표의 모양을 이해하기 어려움 | 실제 줄바꿈·탭을 사용하는 예시로 변경 |

결과 보기의 미입력 수는 그룹·역할·농도 등 배치 정보가 있고 분석에서 제외하지 않은 well을 대상으로 합니다. 결과 0은 입력된 값으로 처리합니다. 입력 수에는 제외된 well의 기존 결과도 포함하며 제외 수는 별도로 표시합니다. 결과 단위를 함께 나열하고, 각 well 상세 및 접근성 설명에는 원래 정밀도의 값과 단위를 유지합니다. grid 숫자는 표시용으로 반올림하며 저장값과 분석 계산은 바꾸지 않습니다. 색은 상태를 구분하는 용도이며 수치의 크기나 유의성을 뜻하지 않습니다.

## 다음 개선 우선순위

| 우선순위 | 불편/확인된 제약 | 권장 수정 |
|---|---|---|
| 높음 | 개별 결과 입력은 well 선택 → 편집 → 저장을 반복해야 함 | 결과 전용 입력 화면에 `저장 후 다음 well`과 이동 방향 선택 제공. 실패 시 현재 draft 유지 |
| 높음 | 가져오기 미리보기는 처음 일부 좌표와 개수 중심 | 적용 전 전체 96-well 매핑, 기존 값과 변경값 비교, 행·열 시작 위치 표시 |
| 높음 | 실험 상세에서 기본정보·단계·자원·메모가 긴 화면에 섞임 | 설계/실행/결과 단계로 분리하고 실행 중에는 단계·타이머를 먼저 표시 |
| 높음 | 분석의 control은 같은 결과 단위에서 역할 우선순위로 묶임 | 약물/용매 조건별 기준 control 선택. 분석표에 비교 대상과 적용 범위를 명확히 표시 |
| 중간 | 확대 상태에서 행·열 헤더가 화면 밖으로 사라질 수 있음 | 고정 행·열 헤더와 좌표 직접 이동. 이번에는 칸별 좌표 표시로 위치 확인을 보완 |
| 중간 | 타이머는 시작/완료와 경과 시간 중심 | 프로토콜별 예정 시간, 일시정지 정책, 앱이 닫혀도 동작하는 알림을 별도로 설계 |
| 중간 | 숫자·단위 입력에서 실험 종류별 기본값이 부족함 | OD450/OD570/RFU 등의 선택과 최근 사용 단위, 과학 표기 입력 동선 개선 |
| 중간 | 생성 버튼이 홈 여러 곳에 있고 기능명이 한영 혼용됨 | 주요 생성 동선 정리, `배치/측정/분석` 기준 용어 통일 |

control 선택, 다음 well 저장, 백그라운드 알림은 계산 정책·저장 실패 처리·OS 동작까지 함께 설계해야 하므로 이번 표시 개선과 분리했습니다.

## 검증과 실기기 확인

- 위젯 테스트: 기본 48dp, 확대/전체 보기, 행 선택 유지, 0 결과/미입력/제외 구분, 정확한 값의 접근성 설명, 320px와 글자 1.6배, 가로 스크롤, 완료 상태 조회, 선택 중 결과 가져오기.
- 회귀 검증: 기존 데이터 저장·복구·백업·분석 테스트 및 플랫폼 빌드.
- 남은 실기기 QA: 장갑 착용 후 A1/B1 오선택 빈도, 12채널 피펫 이동 중 좌표 확인, H12까지 스크롤, VoiceOver/TalkBack, 실제 Plate reader 파일과 공유 동선. 48dp만으로 장갑 사용성이 충분하다고 단정하지 않습니다.
