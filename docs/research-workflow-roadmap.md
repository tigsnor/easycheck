# 실험연구원 관점의 기능 개선 제안

검토일: 2026-10-23 (한국 시간). 현재 코드와 테스트를 바탕으로, 한 연구자가 오프라인에서 96-well 실험을 설계하고 수행·기록·분석하는 흐름을 검토했습니다. 실제 연구원 인터뷰나 장갑 착용 실기기 검증 결과는 아닙니다. 아래 제안은 구현 완료 항목과 구분하며, 임상·규제 시스템 적합성을 의미하지 않습니다.

## 이번에 구현한 다음 작업: 결과 연속 입력

- Plate 하단 또는 더보기의 `결과 연속 입력`에서 선택한 well부터 시작합니다. 선택이 없으면 A1입니다. 여러 well을 선택했더라도 선택 영역에 한정하지 않고 현재 좌표부터 Plate 끝까지 이동합니다.
- 행 방향은 A1 → A2 → … → A12 → B1, 열 방향은 A1 → B1 → … → H1 → A2입니다. 다음 좌표를 저장 전에 표시합니다. 방향은 입력 중 바꿀 수 있습니다.
- `저장 후 다음 well`은 저장 성공 후에만 이동합니다. H12에서는 `저장 후 마치기`로 종료하며 처음으로 돌아가지 않습니다. 중간에는 `현재 well 저장 후 닫기`를 사용합니다.
- 현재 값·단위만 저장하고 농도·역할·메모·그룹·분석 제외 상태를 유지합니다. 0과 음수, 유한한 과학 표기 숫자를 허용하고 빈 입력·NaN·무한대는 차단합니다. 결과 삭제는 기존 well 편집을 사용합니다.
- 다음 well의 기존 값·단위와 제외 상태를 보여줍니다. 결과가 없는 well에는 직전에 입력한 단위를 기본으로 넣되, 기존에 단위가 저장되어 있으면 그 단위를 우선합니다. 기존 측정값의 단위가 없으면 임의로 채우지 않습니다.
- 빈 well과 제외 well도 이동 순서에 포함됩니다. 자동 건너뛰기로 좌표가 예상과 달라지지 않도록 범위를 안내합니다. 방향 변경으로 이미 저장한 좌표를 다시 만나도 이번 입력 중 저장한 최신 값을 표시합니다.
- 저장 실패 시 현재 좌표와 입력을 유지하며 수정·재시도할 수 있습니다. 저장 중 중복 저장·닫기·뒤로가기를 차단합니다. 미저장 입력을 닫을 때 폐기를 확인하고, 앞서 저장된 결과는 유지합니다. 강제 앱 종료 후 미저장 입력 복구는 아직 지원하지 않습니다.
- 각 저장은 기존 Plate 변경 이력과 실행 취소에 연결되며 완료된 실험에서는 입력 기능을 제공하지 않습니다. 이력 보관은 기존 최근 20건 정책입니다.

## 기존 기능에서 수정할 부분

2026-10-23 후속 구현: 결과 일괄 입력에 `전체 96개 well 비교`를 추가했습니다. Plate 배치에서 모든 좌표의 상태를 확인하고, 선택한 well의 기존값·적용 후 값·단위를 하단에서 정확한 정밀도로 읽을 수 있습니다. 값 비교 목록에는 전체 항목 또는 실제로 값/단위가 바뀌는 항목만 표시합니다. 빈 셀은 기존 데이터를 유지하고, 숫자가 같아도 단위가 바뀌면 덮어쓰기로 계산합니다. 미리보기는 실제 적용과 같은 변환을 사용하며 저장은 기존 적용 버튼에서 진행합니다. 모호한 첫 행과 잘못된 값은 먼저 해결해야 합니다.

## 검증과 남은 확인

자동 테스트는 연속 입력의 0/유한값 검증, 저장 실패·재시도, 중복 저장 차단, 미저장 입력 폐기 확인, 행·열 경계, 마지막 well 종료, 방향 변경 후 최신값, 기존 데이터 보존, 변경 이력·실행 취소, 완료 실험 입력 잠금, 320px·글자 1.6배·키보드 여백을 다룹니다.

실기기에서는 장갑 착용, 한 손 조작, 실제 키보드에서 음수·과학 표기 입력, 스크린리더 좌표 안내, 앱 전환 중 저장, Plate reader 원본 파일별 형식을 확인해야 합니다. 후속 기능은 실험 유형과 장비 파일 사례를 확인한 뒤 범위를 좁혀 구현합니다.

## 조건별 분석 기준 선택 (2026-10-26 구현)

- Plate 분석 → `그룹명 · 결과 단위 기준 설정`에서 자동 모드를 끄고 Blank와 Control well을 선택합니다. 동일 그룹·결과 단위의 모든 농도와 역할에 적용하며, 다른 단위와 그룹에는 적용하지 않습니다. 그룹이 없는 well은 `그룹 없음` 대상에 함께 묶입니다.
- 자동 기준은 기존과 동일하게 같은 결과 단위의 유효한 Blank 전체, Vehicle → Untreated → Negative 중 첫 번째 존재하는 역할의 유효한 control 전체입니다. 수동 선택 가능한 control도 이 세 역할입니다. Positive control의 두 기준점 정규화는 지원하지 않습니다.
- 수동 기준은 선택한 well 평균을 사용합니다. 처리군과 Control 모두 같은 선택 Blank 평균을 빼고, 그 비율을 100배합니다. Blank를 선택하지 않으면 보정 없이 원값을 사용하고 Control을 선택하지 않으면 정규화하지 않습니다. 화면에 이러한 상태를 안내합니다.
- 저장한 기준 well이 제외·미입력·다른 단위/역할·없는 좌표가 되면 그 좌표를 표시합니다. 일부만 남겨 계산하거나 자동 기준으로 대체하지 않습니다. 잘못된 Blank는 보정 및 정규화를, 잘못된 Control이나 0 분모는 정규화를 중단합니다. 원값·SD·CV는 그대로 조회할 수 있습니다.
- 각 분석 항목과 TSV에 자동/수동, 선택 좌표, 평균, 경고를 표시합니다. TSV의 `Applied references by series`가 실제 적용 기준이며, `Automatic references`는 자동 모드용 요약입니다. Series에 group_id를 추가하여 동명 그룹도 구분합니다. 수치는 소수점 6자리 절삭 없이 내보냅니다. 차트는 그룹 ID·역할을 구분하고 보정 불가 시 원값임을 표시합니다.
- 저장 실패 시 선택을 유지하고 재시도합니다. 저장 중 닫기·뒤로가기·중복 저장을 막고 미저장 변경 폐기를 확인합니다. 완료된 실험에서는 기준 변경도 잠깁니다.
- 기준은 Plate 파일·백업·변경 이력 스냅샷·실행 취소에 포함됩니다. Plate 파일 버전 2, 백업 버전 3으로 저장하며 기존 파일/백업은 자동 기준으로 읽습니다. 이전 앱에서 새 데이터를 편집하지 않도록 버전을 올렸습니다. 템플릿 적용·새 설계 복제에는 측정 결과용 기준을 이월하지 않습니다.
- 작은 화면·큰 글자에서 저장 상태와 분석 제목이 넘치던 배치도 수정했습니다.
- 자동 검증: 서로 다른 조건의 수치, 미입력/제외/단위/역할 변경, 기준 없음·없는 좌표·0 분모, 파일·백업·이력 복원, 취소·실패/재시도·중복 저장 방지·실행 취소, 읽기 전용, 320px·글자 1.6배. 실제 reader 결과와 연구자의 기준 설정 검토는 후속 실기기 QA입니다.
