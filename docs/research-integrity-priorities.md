# 기존 기능 개선 우선순위

2026-10-28 사용성 점검과 실험 절차 점검을 통합했습니다. 데이터의 의미가 바뀌거나 입력을 잃는 문제를 먼저 고치고, 실험 실행·분석의 판단 근거를 강화한 뒤 반복 조작을 줄입니다. 시료/세포 배치·QC 지도 같은 신규 기능보다 아래 기존 기능 개선을 먼저 진행합니다. 실제 기기 QA는 각 작업과 병행합니다.

## 현재 우선순위 변경 (2026-11-03 연구자 검토)

사용자 요청으로 다음 1~5 순서를 적용합니다. 아래 기존 작업 번호와 과거의 “다음 개발” 문구는 당시 진행 기록이며, 현재 순서는 이 목록을 우선합니다.

1. 완료: 미입력 세포 정보 자동 저장 방지, 결과 단위·파장 결합 수정, 생성 실패 초안 보존
2. 완료: 세포 계수 × 10^지수 입력 통일·실제 값 미리보기와 노트/Plate 중복 입력 정리
3. 구현 완료: 세포·배지 부분 수정, 배지만 전체 교체하는 경로, Blank 보정 상태 표시
4. 구현 완료: 같은 조건 선택·탭별 작업 버튼·좌표 이동·고정 헤더, 홈 필터·임박 단계
5. 다음 작업: 파종 부피·환산, 조건별 배지 일괄 계산, 측정 회차 확장

예정 시간 단위와 이력·백업·삭제 복구 보완은 후속입니다. 지수 표현은 숫자 입력 방식이며 cells/mL·cells/well 단위 환산과 구분합니다. 현재 well 부피를 과거 파종 부피로 추정하지 않습니다.

## 실기기 피드백 우선 작업 (2026-10-30)

사용자가 2026-10-29 실기기 테스트에서 발견한 아래 세 가지를 기존 후속 작업보다 먼저 진행합니다. 순서는 **제목 누락 안내 → 같은 Plate의 여러 세포 종류·농도 → UI 가독성**입니다. 이후 기존 3차의 오시작 취소·재시작 기록 보존으로 돌아갑니다.

| 우선순위 | 문제와 작업 | 완료 기준 | 상태 |
|---|---|---|---|
| P1 | 새 실험 생성 시 제목 누락 안내가 키보드/생성창 뒤에 가림 | 입력란 바로 아래 필수 오류 표시, 제목으로 초점·스크롤 이동, 키보드 위에서 안내 확인, 다른 입력 보존 | 구현·자동 테스트 완료, 실기기 재확인 대기 |
| P2 | 같은 Plate에 여러 세포 종류와 두세 개 이상 세포 농도를 배치해야 함 | well/선택 영역별 세포 종류·농도와 단위를 입력·비교하고 저장·복원; 약물 처리 농도와 구분하며 기존 세포 정보 보존; 분석 조건 분리 | 구현·자동 테스트 완료, 실기기 확인 대기 |
| P3 | 색상 등으로 UI 가독성이 떨어짐 | 주요 화면의 글자/배경 대비, 보조 문구·선택/비활성 상태 점검; 색 외에 텍스트/아이콘으로 구분; 작은 화면·큰 글자 검증 | 공통 테마·well 표시 구현·자동 테스트 완료, 실기기 재확인 대기 |

P2는 한 Plate에 세포 종류와 농도를 하나로 제한하지 않는 요구사항입니다. 아래 구현으로 well/영역별 조건을 지정하며, P3의 공통 테마·well 표시도 아래와 같이 개선합니다. 실제 기기의 가독성 재확인은 계속 병행합니다.

### P1 수정 내용

회귀 테스트 3개를 추가했으며 전체 337개 테스트·정적 분석·포맷 검사를 통과했습니다. 키보드 열림/닫힘, 320px·글자 1.6배에서 오류 위치·초점·입력 보존·공백 거절·수정 후 생성을 검증했습니다.

- 제목 입력란에 `필수 입력`을 표시하고, 빈 값 또는 공백만 있는 상태에서 `생성`을 누르면 `실험 제목을 입력해주세요.`를 입력란 아래에 표시합니다. 생성창 뒤에 가려지는 Snackbar는 사용하지 않습니다.
- 제목으로 초점을 옮기고 상단으로 스크롤합니다. 키보드 높이를 스크롤 영역 바깥에 반영하여 입력란과 오류 안내가 키보드 위에서 보이도록 합니다.
- 오류는 유효한 제목을 입력하면 사라지며, 다시 비우면 표시됩니다. 프로젝트·메모 등 다른 입력과 생성창은 유지되고, 제목 누락 상태에서는 실험이나 Plate를 저장하지 않습니다.
- 데이터/백업 형식은 바꾸지 않습니다. Android/iOS 실제 키보드에서 재확인은 [수동 QA](manual-qa-checklist.md)에 남깁니다.

### P2 수정 내용 (2026-10-30)

회귀 테스트 16개를 추가하고 전체 353개 테스트·정적 분석·포맷 검사를 통과했습니다. 종류·농도·단위별 집계/기준 분리, 파일·템플릿·백업·설계 복제 보존, 일괄 지정/해제·읽기 전용·입력 보호·저장 실패 재시도·작은 화면의 키보드 오류 안내를 검증했습니다.

- well 하나, 행/열 또는 드래그 선택 영역에서 하단 `세포 조건`을 눌러 세포 종류와 세포 농도/파종 수를 지정합니다. 같은 Plate에 HEK293 5,000 cells/well, HEK293 10,000 cells/well, HeLa 5,000 cells/well 등을 각각 배치할 수 있습니다. 조건 개수를 두세 개로 제한하지 않습니다.
- 세포 종류는 직접 입력하며 농도는 선택입니다. `cells/mL`와 `cells/well`을 구분하고 자동 환산하지 않습니다. `1e5` 같은 과학 표기를 허용하며 음수·NaN·무한대를 거부합니다. 농도가 없으면 임의의 숫자나 단위를 채우지 않습니다.
- 같은 Plate의 조건을 불러와 재사용합니다. 여러 조건이 선택되면 일괄 변경임을 안내하며 `세포 조건 해제`는 확인 후 세포 종류·농도만 제거합니다. 약물 농도·그룹·역할·결과·메모·제외 여부는 유지합니다.
- `세포` 보기에서 C1/C2 등 표시 번호와 세포 종류·농도·단위·well 수를 확인합니다. C 번호는 현재 배치의 표시용이며 영구 식별자가 아닙니다. 정확한 조건은 well 상세에서도 확인합니다.
- 기존 노트 전체의 세포수 문구는 보존하며 임의로 well에 배분하지 않습니다. 세포 조건을 추가로 지정해야 분석에서 구분됩니다. 노트 생성·편집 화면에도 이를 안내합니다.
- 반복값, 평균·SD/CV, 차트, 반복 부족 점검과 분석 기준을 세포 종류·농도·단위별로 분리합니다. 명칭은 입력한 표기가 같아야 같은 종류로 묶으며, 대소문자·단위의 자동 통합은 하지 않습니다. 미지정 조건은 지정 조건과 별도로 취급합니다.
- 자동 Blank/Control은 같은 세포 조건·결과 단위에서만 찾습니다. 수동 Control도 같은 세포 조건으로 제한합니다. 세포 미지정 Blank는 배지·용매 조건을 연구자가 확인한 후 공통 기준으로 직접 선택할 수 있습니다. 다른 세포 종류·농도의 Control을 자동으로 빌려오지 않습니다. 기존의 그룹별 수동 기준은 세포 미지정 조건에 유지되며 새 조건으로 자동 복사하지 않습니다.
- 결과가 있는 well의 조건 변경/해제는 기존 측정 후 정정 확인·사유를 거칩니다. 변경 전 조건과 측정값은 이력에 보존하며, 저장 실패 시 기존 Plate 재시도/폐기 흐름을 사용합니다. 확인을 취소하면 적용하지 않습니다. 완료·보관 Plate의 편집 잠금도 유지합니다.
- Plate 파일 v3, 템플릿 파일 v2, 전체 백업 v7로 저장합니다. 이전 형식도 읽으며 세포 조건은 미지정으로 유지합니다. 실험 파일은 v4 그대로입니다. 템플릿·설계 복제는 세포 배치를 보존하되 결과를 초기화합니다. Plate/분석 TSV에 `cell_type`, `cell_density`, `cell_density_unit` 열을 추가합니다.
- 미저장 입력의 앱 종료 후 복구, 이력 최근 20건 한도는 기존 정책과 같습니다. Android/iOS 실제 키보드·장갑 조작과 기존 데이터 업데이트 후 비교는 수동 QA로 확인합니다.

### P3 수정 내용 (2026-10-30)

2026-10-31 사용자 요청으로 후속 색상을 슬레이트·틸로 변경했습니다. 주요 동작은 `#0F766E`, 선택된 탭·필터는 `#CCFBF1`, 본문은 `#1E293B`이며 카드·팝업·하단 시트는 흰색입니다. 배경을 중립색으로 명시해 자동 색조가 섞이지 않도록 하고 Plate·분석·백업의 일반 배경도 공통 테마에 맞췄습니다. 실험군과 결과 상태의 의미를 가진 색상은 유지합니다.

새 테스트 5개와 전체 358개 테스트·정적 분석·포맷 검사를 통과했습니다.

- 밝은 바탕 위에서 약 1.4:1 대비였던 노란 primary 대신 진한 파란색을 버튼·링크·선택·저장 중·그래프 강조에 사용합니다. 기본 배경은 중립색으로, 본문/보조 문구는 진한 회색으로 정리합니다.
- 보조 본문 크기를 12→14px, 작은 라벨은 12px 이상으로 조정합니다. 힌트·입력 오류 색상을 명시하고, 버튼 최소 높이를 48px로 맞춥니다. 비활성 버튼은 읽을 수 있는 회색 글자와 배경으로 표시하되 비활성 동작은 유지합니다.
- 저장된 그룹 색상은 바꾸지 않습니다. well의 실제 표시 배경 위에서 검정/흰색 중 대비가 높은 글자를 사용하고, 선택 테두리도 같은 대비색으로 그립니다. 선택된 well에는 `✓`를 추가해 색과 별개로 선택 상태를 구분합니다. 스크린리더의 선택 상태도 유지합니다.
- Plate 헤더를 중립색으로 바꾸고 완료/정상 표시의 초록색을 진하게 조정합니다. 세포 보기 안내는 읽기 전용 Plate에서도 맞는 설명으로 바꿉니다.
- 테스트에서 주요 테마 조합·저장 상태·대표 그룹 배경의 글자와 선택 테두리 대비 4.5:1 이상, 실제 앱 테마의 320px·글자 1.6배·키보드 상태에서 생성/세포 조건 입력을 확인합니다. 실제 조명 아래의 가독성은 수동 QA에서 확인합니다.
- 데이터/파일/백업 형식과 기록값에는 변경이 없습니다. 실기기에서 낮은 화면 밝기·색각 차이·장갑 조작을 재확인한 뒤 추가 조정합니다. 오시작 취소·재시작 기록 보존은 아래 2026-10-31 후속에서 구현했습니다. 실제 시각 사후 입력과 단계 생략 사유도 아래 후속에서 구현했습니다. 4차의 배지·용매 조건별 분석 기준 분리까지 구현했습니다. 다음 개발은 기존 배지 추가/교체 계산입니다.

## 작업 순서와 완료 기준

2026-11-03 사용자 요청으로 **7번 반복 조작 감소를 남은 5·6번보다 먼저 진행**합니다. 번호는 기존 작업 묶음 식별용으로 유지합니다. 선택 well 연속 입력·건너뛰기·단위 재사용·지수 입력 보조를 구현했고, 다음은 Plate 좌표 이동·고정 헤더, 이후 홈 필터·임박 단계입니다. 분·시간·일 입력과 이력·백업·삭제 복구는 후순위입니다.

| 순서 | 작업 묶음 | 포함할 항목 | 완료 기준 | 상태 |
|---|---|---|---|---|
| 1 | 기록·입력 보존 | well 단위·역할의 의도하지 않은 변경 방지, 개별 well 미저장 입력 보호, 완료 체크 시 미기록 시작 시각 보존 | 메모/제외만 변경하면 기존 측정 조건 보존; 닫기 시 폐기 확인; 시작 없는 완료·완료 해제·재실행·백업 복원에서도 시작/알림을 만들어내지 않음 | 구현·자동 테스트 완료 |

## 1차 수정의 동작

- 개별 well 편집은 농도/결과 단위가 없으면 빈 입력으로 열고 그대로 미지정으로 저장합니다. 신규 값도 단위를 자동 선택하지 않습니다. 예시 단위는 입력 힌트입니다.
- 메모·분석 제외만 변경하면 기존 수치·단위·역할·부피·반복 번호를 보존합니다. 측정값 없이 단위만 저장된 기록도 유지합니다. 기존 빈 역할에 농도가 이미 있던 경우 메모 수정만으로 Treatment로 바꾸지 않습니다. 농도를 처음 입력하는 경우의 Treatment 기본 역할은 유지합니다.
- 단위 변경/비우기는 사용자의 명시적인 입력으로 처리합니다. 기존 측정값 자체를 지우면 그 결과 단위도 지우는 기존 동작은 유지합니다. 농도 값 삭제 시 농도 단위는 입력 내용대로 보관합니다.
- 변경 없는 저장은 쓰기와 새 변경 이력을 만들지 않고 닫습니다. 오류 후 원래 값으로 되돌려 닫는 경우도 같습니다.
- 개별 well 편집의 바깥 터치·드래그 닫기를 차단합니다. 닫기 버튼 또는 시스템 뒤로가기에서 변경이 있으면 `계속 편집 / 입력 버리고 닫기`를 선택합니다. 변경이 없으면 바로 닫습니다.
- 명시적 저장 후 파일 쓰기가 실패하면 기존 Plate 저장 실패 배너와 재시도를 통해 동일한 초안을 다시 저장합니다. 미저장 편집창 자체를 앱 강제 종료 후 복구하는 기능은 이번 범위에 없습니다.
- 시작하지 않은 단계의 완료 체크는 완료 버튼을 누른 시각만 기록하고 `시작 시각 미기록`으로 표시합니다. 소요 시간을 0으로 계산하지 않습니다. 과거 완료 기록에 완료 시각도 없으면 `완료 시각 미기록`으로 표시합니다.
- 완료 체크를 해제해도 없던 시작 시각은 만들지 않습니다. 원래 시작 기록이 있으면 기존처럼 그 시각을 유지합니다. 단계 변경은 아직 상단 저장이 필요하며 자동 저장 연결은 3차 범위입니다.
- 파일/백업 형식 변경은 없습니다. 새 미기록 상태는 기존 nullable 시각 필드로 저장·복원합니다. 과거 앱이 이미 채워 넣은 시작 시각은 실제 시각인지 구분할 수 없으므로 자동 삭제하지 않습니다.

- 기존 미지정 조건끼리의 분석은 유지하지만 조건 일치를 보장하지 않습니다. 분석 화면에서 안내하며 기록 확인 후 조건을 입력할 수 있습니다.
- 측정값이 있는 well의 조건 변경은 기존 정정 사유·변경 전후 이력을 거칩니다. 결과·제외 상태는 유지되며 읽기 전용 보호와 저장 실패 재시도도 적용됩니다.
- 원본/분석 TSV, Plate 재실행, 템플릿, 설계 복제, 변경 전 스냅샷과 백업에 조건을 보존합니다. Plate v4·템플릿 v3·백업 v10이며 이전 파일은 누락된 조건을 미지정으로 읽습니다. 실험 파일은 v6을 유지합니다.
- 계산 분리·기준 변경 무효화·미지정/0 구분·저장/복원·작은 화면/큰 글자/키보드·실패 재시도를 자동 검증합니다. 실기기 조작은 수동 QA로 남습니다.

## 후속 요청: 세포·배지 탭과 독립 색상 (2026-11-01)

사용자 요청에 따라 다음 희석 계산 작업보다 먼저 반영했습니다. 배치 탭을 제거하고 세포(기본)/배지/결과로 구성합니다. 조건 저장 후 해당 탭으로 이동하며, 결과 입력 진입은 결과 탭을 유지합니다.

| 영향 범위 | 반영/검토 결과 |
| --- | --- |
| 색상과 구분 | 세포 종류·농도·단위와 배지/용매/최종 비율을 각각 독립적으로 자동 색상화합니다. 조건 자체에서 색상을 결정하므로 다른 조건 추가·수정, 그룹 색상 변경, 복원에 영향받지 않습니다. 비슷한 색은 C/M 번호와 정확한 조건 범례로 구분합니다. 번호는 현재 Plate의 표시용입니다. |
| 화면 공간/선택 | 범례를 grid 아래 접이식으로 이동해 초기 96개 전체 보기를 유지합니다. 탭 이동은 선택·배율을 보존하고 진행 중 드래그만 종료합니다. |
| 기존 그룹/희석 | 실험군·처리 농도는 상세·요약에서 확인합니다. 수동 그룹 색상은 실험군 요약용으로 명확히 표시합니다. 세포·배지 색상은 그룹 색상을 따르지 않습니다. |
| 결과/분석 | 결과 진입과 입력·제외 표시는 유지합니다. 같은 조건 색상이어도 실험군·역할·처리 농도가 다르면 기존 분석에서 별도 series입니다. 색상·C/M 번호를 분석 키로 사용하지 않습니다. |

## 4차 2: 기존 배지 추가·교체 계산 (2026-11-01)

세포·배지 탭 변경 후 후속 요청으로 구현했습니다. 선택 well에 대해 추가/일부 교체/전체 교체를 구분하고 잔류 배지의 시약·용매를 반영해 최종 농도·부피·용매 비율을 계산합니다. 계산식과 검산 사례는 [피펫팅 계산 기준](pipetting-plan-method.md)에 정리했습니다.

- 미기록 초기값은 직접 입력하며 0으로 추정하지 않습니다. 같은 단위·같은 시약·한 종류의 용매를 명시적으로 확인하고, 기존 기록과 충돌하면 추가/일부 교체 적용을 막습니다. 전체 교체는 잔류액 0이라는 가정으로 새 용액의 조건만 사용합니다.
- 계산 미리보기 후 별도 확인·기록을 거칩니다. 입력 변경 시 결과를 무효화하고, 취소는 입력 폐기 확인을 거칩니다. 기존 결과·세포 파종 기록·그룹·역할·제외 상태를 보존합니다.
- 조건 변경은 중앙 저장 경로의 측정 후 사유·스냅샷·저장 실패 재시도를 이용합니다. 입력/제거/잔류/최종 조건은 이력에 포함됩니다. 실제 작업 완료나 실행 단계는 변경하지 않습니다. 기존 최근 20건 이력 한도도 유지합니다.
- 분석/조건 색상은 갱신된 배지·용매 조건에 따라 재계산됩니다. 기존 Plate·템플릿·백업 형식을 유지하며 새 필수 필드는 없습니다.

다음 개발: **4차 3 — well별 분석 제외 사유·해제 이력·제외 전후 비교**.


## 4차 3의 첫 단계: 제외·해제 사유 (2026-11-02)

사용 한도를 고려해 well 편집에서 분석 제외 상태가 바뀔 때 사유를 필수 입력하도록 먼저 구현했습니다. 기존 변경 이력에 좌표·제외 전후 상태·사유와 저장 시각을 보존하고, 저장 실패 재시도에서는 같은 이력을 사용합니다. 원본 측정값은 제외 조작으로 변경하지 않습니다. 기존 제외 well의 메모 수정에는 새 사유를 요구하지 않습니다. 저장 형식과 백업 구조는 유지합니다.

이번 필수 사유는 개별 well 편집에 적용하며 이력 복원·실행 취소·템플릿 적용은 기존 절차를 유지합니다. 현재는 기존 최근 20건 이력을 사용하므로 영구 감사 기록이나 별도 well별 사유 조회 기능은 아닙니다. 이후 아래 후속 구현에서 전용 이력 보관·조회와 가상 포함 비교를 연결했습니다.


## 4차 3 후속: 전용 제외 이력·가상 포함 비교 (2026-11-02)

- `더보기 → 제외 이력·분석 비교` 또는 well 상세의 바로가기로 조회합니다. 전체/좌표별로 필터링하고, 완료/보관된 읽기 전용 Plate에서도 확인할 수 있습니다.
- 제외·해제 전용 이벤트에 좌표, UTC 변경 시각, 전후 제외 상태, 사유/변경 경로, 당시 측정값·단위를 저장합니다. 개별 편집 외 실행 취소·스냅샷 복원·템플릿 적용에 의한 상태 변화도 기록합니다. 저장 실패 재시도는 원래 이벤트 ID·시각을 보존하고 중복 추가하지 않습니다.
- 전용 이벤트는 전체 Plate 스냅샷의 최근 20건 제한과 분리하며 자동으로 잘라내지 않습니다. 앱 내 실행 취소와 스냅샷 복원도 기존 이벤트를 유지하고 반대 방향 변경을 덧붙입니다. 전체 스냅샷 보관 한도 개선은 6차에 별도로 남습니다.
- 이전 버전의 사유/시각은 문자열을 해석해 재생성하지 않습니다. 남아 있는 전체 변경 이력에서 조회하며, 이미 삭제된 기록은 복구할 수 없습니다. 과거 백업으로 전체 복원하거나 Plate를 삭제하면 이후 이벤트가 없어질 수 있습니다. 외부 변조를 방지하는 영구 감사 시스템은 아닙니다.
- 비교는 현재 측정값·조건·수동 기준을 유지한 채 선택 범위의 제외만 가상 해제합니다. 평균·표본 SD·CV·Blank 보정·Control 대비 비율과 적용 기준/경고를 나란히 표시합니다. 제외된 기준 well이 다른 처리군에 미치는 영향도 전체 분석 엔진으로 재계산합니다. 조건·단위가 다른 기준을 섞지 않고 미입력/모두 제외/무효 기준은 0으로 대체하지 않습니다.
- 현재와 가상 결과의 비교이며 과거 시점의 전체 분석 재현이 아닙니다. 조회/필터/가상 포함은 저장·이력 변경을 만들지 않습니다. Plate v5·백업 v11로 저장하고 이전 형식을 읽습니다. 템플릿과 설계 복제에는 수행 이력을 가져오지 않습니다.

## 5차 1: 실행 전 단계 구성 편집 (2026-11-02)

- 실험 노트의 `실행 → 단계 구성 편집`에서 이름 수정·추가·삭제·위/아래 이동을 제공합니다. 수행 기록이 없는 초안·계획 실험에만 적용하며, 시작 취소로 현재 시각이 지워져도 이전 수행 이력이 있으면 잠깁니다.
- 기존 단계 ID·예정 시간·알림 설정은 그대로 유지합니다. 최소 한 단계를 유지하고 빈 이름은 입력칸에서 안내합니다. 삭제와 미적용 변경 폐기는 확인을 거칩니다.
- `노트에 적용`은 편집 초안에 반영하며 상단 `저장`으로 파일에 저장합니다. 기존 단계 이름·순서·삭제 변경이 미저장 상태이면 시작·완료·실제 시각·생략 등의 실행 기록을 막습니다. 저장 실패 시 메모·단계 초안을 유지해 재시도합니다.
- 새 단계만 추가하거나 예정 시간만 바꾼 경우는 기존 단계별 즉시 저장 흐름을 유지합니다. 기존의 별도 단계 추가 기능도 유지합니다. 시작한 뒤 기존 단계의 이름·순서·삭제를 편집하는 기능은 이번 범위에 포함하지 않습니다.
- 파일/백업 형식 변경 없이 기존 task 데이터로 저장합니다. 단위 테스트와 화면 테스트는 저장 실패·재시도·수행 기록 보호·320px/큰 글자/키보드 입력 오류를 확인합니다. 실제 키보드와 장갑 조작은 수동 QA로 남깁니다.

## 5차 2: 수행 후 단계 변경 사유·기록 보존 (2026-11-03)

- 진행 중·정정 중이거나 수행 이력이 있는 실험에서도 단계 이름·순서를 편집하고 미수행 단계를 추가·삭제할 수 있습니다. 현재 수행 시각·완료/생략·과거 실행 이력·단계 ID는 유지합니다. 시작 취소 이력만 남은 단계도 삭제할 수 없고, 중단은 기존 단계 생략으로 기록합니다.
- 구성 변경을 노트에 적용한 뒤 저장하면 변경 전후 순서와 추가/삭제/이름 변경을 확인하고 사유를 입력합니다. 기존 별도 단계 추가 경로도 같은 저장 확인을 거치며, 미저장 구성 변경이 있으면 실행·완료·생략·실제 시각 입력이 잠깁니다. 수행 기록 없는 초안·계획의 새 단계 즉시 실행 저장은 유지합니다.
- 사유 입력 취소 시 단계·메모 초안을 유지합니다. 저장 중에는 추가 변경·중복 저장·화면 이탈을 막습니다. 실패 재시도는 승인한 사유·시각·이력 ID와 전후 단계를 그대로 사용하고 이력을 중복 추가하지 않습니다. 알림은 저장 성공 후 기존 예약 동기화에서 같은 단계 ID·마감 시각으로 이름을 갱신합니다.
- 결과 화면의 변경 이력에서 당시 전후 구성을 읽기 전용으로 조회합니다. 변경 전 노트에는 수행 시각·사후 기록·생략 사유·과거 실행 이력을 보존하며, 변경 후 단계 스냅샷은 이후 편집과 독립적입니다. 완료·보관 잠금과 완료 후 정정·재검토 절차는 유지합니다.
- 실험 파일 v7·전체 백업 v12로 전후 단계 스냅샷을 보존하며 이전 파일/백업도 읽습니다. 설계 복제는 기존처럼 변경 이력을 복사하지 않습니다. 예정 시간 단위 확장과 시간 설정 변경의 별도 감사 정책은 이번 범위가 아닙니다.

## 5차 3: 유형별 추천 체크리스트 비교·적용 (2026-11-03)

- 설계 화면의 실험 유형 선택 또는 `추천 단계 비교`에서 현재 구성과 추천 구성을 확인합니다. 기본은 기존 단계 유지이며 추천 단계로 교체 또는 빠진 추천 단계 추가를 직접 선택하고 `노트에 적용 → 저장`합니다. 취소하면 유형 표시와 단계 초안이 그대로 유지됩니다.
- 추천은 키트·실험실 SOP와 대조할 편집 가능한 체크리스트 초안입니다. CCK-8/MTT 시약 단계를 구분하고 일반적인 MTT의 Formazan 생성·용해 단계를 별도로 표시합니다. 농도·반응 시간·알림을 임의로 지정하지 않습니다. 저장된 기존 실험의 단계는 자동으로 바꾸지 않습니다.
- 전체 교체는 수행 전 초안·계획에만 허용합니다. 같은 이름의 기존 단계는 ID·시간·알림을 유지하고, 여러 개면 첫 단계가 대응됩니다. 추천에 없는 기존 단계는 삭제 목록을 확인하고 적용합니다. 추가는 기존 순서·수행 기록을 모두 유지하며 이름이 없는 추천 단계만 뒤에 붙입니다. 같은 추천을 다시 추가해도 중복 생성하지 않습니다.
- 수행 후 유형만 바꾸는 경우도 저장 시 전후 유형과 사유를 확인하며 기존 이력 필드의 요약에 당시 유형 변경을 보존합니다. 미저장 유형 변경 중 실행 기록을 막고 실패 재시도는 같은 사유·시각·원본·유형을 유지합니다. 파일/백업 버전은 v7/v12 그대로입니다.
- 완료·보관 잠금과 정정 흐름은 유지하며, 전체 교체 금지는 노트에서 상태를 초안/계획으로 되돌리는 미저장 변경으로 우회하지 못합니다. 자체 SOP 파일 가져오기/템플릿 관리 기능은 이번 범위가 아닙니다.

## 반복 조작 감소 1차 — 선택 well 연속 입력 (2026-11-03)

- 여러 well을 선택하면 선택 범위만 입력하는 방식으로 시작합니다. 입력창을 열 때 대상을 고정하므로 Plate 강조 좌표가 바뀌어도 범위는 유지됩니다. 행/열 방향을 바꾸면 아직 처리하지 않은 선택 well만 방문합니다.
- 선택이 없거나 하나면 기존처럼 현재부터 끝까지 입력하며, 선택이 있으면 범위를 전환할 수 있습니다. 범위를 바꾸며 현재 입력을 버려야 하는 경우 확인합니다.
- 저장 없이 건너뛰기는 기존 결과·단위·메모·제외 상태와 변경 이력을 유지합니다. 수정했거나 저장에 실패한 입력은 폐기를 확인합니다. 저장 중 이동·중복 저장을 막고 실패 시 입력을 유지합니다.
- 성공적으로 저장한 단위를 다음 빈 well에 이어 쓰며, 같은 Plate 편집 화면에서 입력창을 다시 열 때도 재사용합니다. 최근 단위와 Plate의 기존 단위 칩은 현재 입력칸만 변경합니다. 최근 순서는 편집 화면을 나가면 초기화되며 앱 전체 영구 설정은 아닙니다. 기존 단위 없는 측정값은 자동으로 채우지 않습니다.
- 숫자 키보드 옆 `-`, `.`, `지수 e` 버튼은 현재 커서/선택 위치에 문자를 입력합니다. 기존 유한 숫자 검증과 정밀도, 조건 정정 검토·이력·실행 취소를 유지합니다. 파일·백업 형식은 변경하지 않습니다.
- 자동 테스트로 비연속 선택·방향 변경·마지막 대상 종료·범위 전환·저장 실패·폐기 취소·기존 데이터 보존·커서 입력·단위 재사용 및 실제 Plate 화면 연결을 확인합니다. 실기기 키보드·장갑 조작은 수동 QA로 남깁니다.

다음 개발: **반복 조작 감소 후속 — Plate 좌표 이동·고정 헤더 → 홈 진행 중/프로젝트 필터·임박 단계**. 이후 예정 시간 단위와 이력·백업·삭제 복구 보완을 진행합니다.

## 연구자 검토 1차: 기록 정확성·생성 입력 보존 (2026-11-04)

- 새 실험에서 세포 이름·계수·지수를 모두 비워두면 참고정보를 저장하지 않습니다. 일부만 입력하면 누락 안내를 표시하며 이름 `cell`, 계수 `1`, 지수 `6`을 임의로 보충하지 않습니다. 음수·비유한값·정수가 아닌 지수·계산 범위 초과를 막고 0은 명시적 입력으로 유지합니다.
- 새 실험은 저장에 성공한 후 입력창을 닫습니다. 실패 시 제목·프로젝트·메모·유형·세포 정보·템플릿 선택을 유지하고 수정·재시도할 수 있습니다. 재시도는 같은 실험 ID와 생성 시각을 사용합니다.
- 저장 중 중복 생성·닫기를 막으며, 작성 중 닫기는 폐기를 확인합니다. 템플릿 저장 등 중간 실패 시 실험과 Plate 정리를 각각 시도합니다. 재시도 전 잔여 데이터를 정리하므로 템플릿을 바꾸거나 해제해도 이전 실패 시도의 Plate가 남지 않습니다. 정리에 실패하면 폐기로 닫지 않고 입력을 유지합니다. 초안은 메모리 내 보존이며 앱 강제 종료 후 복구는 이번 범위가 아닙니다.
- 결과 일괄 입력에서 별도 파장은 plain `OD`(대소문자 무관)에만 적용합니다. RFU·RLU·OD570처럼 완성된 단위는 그대로 저장하고 파장 칸은 비활성화합니다. 단위를 비우면 단위 없이 저장하며 미리보기와 실제 적용은 같은 단위를 사용합니다. OD로 돌아오면 직접 입력한 파장과 행렬을 유지합니다.
- 기존 실험의 참고정보와 기존 결과 단위는 임의 정정하지 않습니다. 파일·백업 형식은 변경하지 않습니다. 형광 여기/방출 채널이나 측정 회차 모델은 후속입니다.

다음 개발은 **2차: 세포 계수 × 10^지수 입력 통일·실제 값 미리보기와 노트/Plate 중복 입력 정리**입니다.


## 연구자 검토 2차: 세포 지수 입력·값 미리보기 (2026-11-04)

- 실험 생성 참고정보와 Plate 세포 조건에서 같은 숫자 입력을 사용합니다. 일반 숫자 `10000`·`1e4`는 왼쪽에만 입력하고, 지수 방식은 왼쪽 `1`과 오른쪽 `4`로 입력합니다. 지수 생략은 일반 숫자 입력을 뜻하며 0배로 해석하지 않습니다. `1×10^4` 표기의 붙여넣기도 허용합니다.
- 숫자를 입력할 때 실제 값과 현재 단위를 즉시 표시합니다. 표시만으로 저장하지 않으며, cells/mL와 cells/well 변경 시 부피 환산을 하지 않습니다. 양쪽 입력이 모두 비었을 때만 수치 미지정으로 처리하며 지수만 입력한 경우와 음수·비유한값·범위 초과는 차단합니다.
- 수치 계산은 십진 표기에서 한 번 변환하여 계수와 10의 거듭제곱을 따로 곱할 때 생길 수 있는 반올림·중간 범위 초과를 피합니다. 기존 세포 값은 원래 수치의 왕복 가능한 문자열로 열며 표시 자릿수를 줄이지 않습니다. 조건 재사용 시 이전 지수는 초기화합니다.
- 생성 시 노트 참고용 세포 정보는 기본으로 접어 둡니다. 실제 well별 조건은 Plate에서 지정하도록 안내하며, 참고정보를 Plate 전체에 자동 배치하거나 기존 참고 메모를 변환하지 않습니다. 참고정보를 작성했다 접어도 입력은 유지됩니다.
- Plate의 세포 종류만 기록하는 기능, 결과가 있는 well의 조건 정정 사유·이력, 실패 재시도·폐기 확인과 원래 단위를 유지합니다. 파일·백업 형식은 변경하지 않습니다. 별도의 파종 부피·단위 환산은 5차입니다.

다음 개발: **3차 — 세포·배지 부분 수정, 배지만 교체하는 간단한 입력, Blank 보정 상태 표시**.


## 연구자 검토 3차: 조건 부분 수정·배지 교체·Blank 상태 (2026-11-04)

- 세포 종류와 수치·단위, 배지와 용매·비율을 각각 `기존 값 유지` 또는 `입력값으로 변경`할 수 있습니다. 서로 다른 조건을 선택하면 기본은 모두 유지이며, 세포 종류만 바꿔도 well별 수치·단위가 남고 배지만 수정해도 well별 용매·비율이 남습니다. 실제 변경이 없으면 저장·정정 이력을 만들지 않습니다.
- 세포 수치·단위는 명시적으로 해제할 수 있습니다. 배지의 `용매 없음 (0%)`은 알려진 무용매 조건이며 미지정과 다릅니다. 세포 종류나 배지가 없는 well에서 필요한 항목을 유지하려 하거나, 미지정 용매를 그대로 두고 새 배지만 지정하려 하면 전체 적용 전에 안내합니다. 조건 불러오기는 두 항목을 변경 상태로 전환하며 전체 조건 해제 확인도 유지합니다.
- `배지만 전체 교체 (시약·용매 없음)`에서는 최종 배지와 well당 부피만 입력합니다. 기존 배지를 전량 제거하는 경우에 한하며, 기존 처리 농도·단위 기록을 해제하고 용매 없음(0%)을 명시합니다. 미지정 처리 농도를 측정된 0으로 저장하지 않습니다. 일부 교체·추가는 기존 계산 경로를 사용하고, 모드나 입력을 바꾸면 다시 계산·확인해야 합니다.
- 선택하지 않은 well과 세포·그룹·역할·결과·메모·제외 상태를 보존합니다. 측정값이 있는 well의 조건 변경은 기존 전후 비교·정정 사유·이력을 거칩니다. 이는 현재 조건 기록의 수정이며, 시간별 배지 교체 이력이나 측정 회차 모델을 새로 만드는 기능은 아닙니다.
- Blank가 없으면 `보정 안 됨 · 원값`으로 표시하고 Control 대비 값도 원값 기준임을 알립니다. 값이 0인 유효한 Blank는 정상 보정에 사용합니다. 유효하지 않은 기준은 확인 필요로 표시하며, 계산값·원값과 자동/수동 기준 선택 규칙은 바꾸지 않습니다.
- 분석 TSV의 Series 마지막에 `blank_correction_status` 열을 추가합니다. 값은 `applied`(적용), `not_applied`(미적용), `invalid_reference`(기준 확인 필요), `unknown`(기준 정보 없음)입니다. 기존 열 순서와 수치, 앱 저장·백업 형식은 유지합니다. 자동 검증과 별도로 실제 기기의 작은 화면·큰 글자·키보드 확인은 수동 QA에 남깁니다.

다음 개발: **4차 — 같은 조건 선택·탭별 작업 버튼·좌표 이동·고정 헤더, 홈 필터·임박 단계**. 파종 부피·환산, 조건별 배지 일괄 계산과 측정 회차 확장은 5차입니다.


## 연구자 검토 4차: 조건 선택·Plate 탐색·홈 작업 찾기 (2026-11-10)

- 세포 탭의 `같은 세포 조건`은 종류·수치·단위, 배지 탭의 `같은 배지 조건`은 배지·용매·비율이 정확히 일치하는 well을 선택합니다. 색상이나 실험군으로 추정하지 않으며 혼합 조건·미지정 선택에서는 비활성입니다. 분석 제외 well도 같은 조건이면 선택에 포함됩니다. 떨어진 좌표는 연속 범위처럼 표시하지 않고 좌표 목록과 개수로 안내합니다.
- 세포 탭은 세포 조건, 배지 탭은 배지·용매와 추가·교체 계산, 결과 탭은 결과 연속 입력을 먼저 표시합니다. 탭 전환 시 작업 메뉴를 처음으로 이동하고 기존 다른 작업은 가로 스크롤로 접근합니다. 선택과 탭 전환은 저장·이력을 만들지 않으며 실제 수정은 선택한 좌표에만 기존 정정·저장 절차로 적용합니다.
- `좌표로 이동`에서 A1~H12를 입력하면 해당 well 하나를 선택하고 화면에 표시합니다. 소문자·앞뒤 공백을 허용하고 잘못된 좌표와 Plate 범위 밖 입력은 안내합니다. 기본 전체 보기는 96개 well을 유지하고 확대 작업 보기는 내부 가로·세로 스크롤과 고정 행·열 헤더를 사용합니다. 헤더 선택·드래그 선택·가장자리 자동 스크롤도 같은 좌표 체계를 따릅니다.
- 홈에서 검색어와 상태·프로젝트 필터를 함께 사용합니다. 기본은 전체이며 프로젝트 미지정도 선택할 수 있습니다. 검색 결과 없음과 실험 자체가 없는 상태를 구분하고 검색·필터 초기화를 제공합니다. 다시 읽기·삭제 등으로 선택한 프로젝트가 사라지면 전체 프로젝트로 돌아갑니다. 필터는 현재 홈 화면에서만 유지하며 저장 형식을 바꾸지 않습니다.
- 홈의 임박·시간 초과 단계는 시작 시각과 예정 시간이 기록된 미완료·미생략 단계 중 예정 종료까지 30분 이내인 항목을 종료 시각순으로 표시합니다. 완료·보관·정정 중인 실험은 제외하며 없는 예정 시각을 추정하지 않습니다. 항목을 누르면 해당 실험의 실행 탭과 단계로 이동하고 기록을 자동 변경하지 않습니다.
- 시간 표시는 필요한 경우 30초마다 갱신하며 앱 복귀 시 즉시 갱신합니다. 백그라운드·화면 종료 시 타이머를 정리합니다. 이는 홈의 예정 종료 안내이며 시스템 알림 예약과는 별개입니다. 실제 기기의 작은 화면·큰 글자·키보드·장갑 조작은 수동 QA로 남깁니다.

다음 개발: **5차 — 파종 부피·환산, 조건별 배지 일괄 계산, 측정 회차 확장**. 현재 배지 부피를 과거 파종 부피로 추정하지 않는 원칙을 유지합니다.


## 연구자 검토 5차 첫 단계: 명시적 파종 부피로 단위 환산

- 세포 조건의 수치 변경에서 `파종 부피로 단위 환산`을 엽니다. 현재 입력한 세포 수치·단위를 기준으로 well당 파종 부피(µL)를 직접 입력해 cells/mL ↔ cells/well을 계산합니다. 단위 드롭다운만 바꾸면 숫자는 환산하지 않습니다.
- 현재 배지 부피를 파종 부피로 추정하지 않습니다. 부피는 이번 계산에만 사용하며 별도 파종 기록으로 저장하지 않습니다. 수식·환산값을 확인하고 입력칸에 반영한 뒤 선택 well 적용으로 저장합니다. 취소는 초안을 보존하며 환산 시 이전 지수를 지웁니다.
- 0 세포 수는 허용하고 0 이하 부피·비유한값·계산 범위 초과/양수 소실은 거부합니다. 측정 후 조건 변경은 기존 정정 사유·이력 경로를 따릅니다.
- 후속: 파종 부피 별도 저장과 이력·백업·내보내기, 조건별 배지 일괄 계산, 측정 회차 확장. 이번 단계는 환산 입력 보조입니다.


## Plate 선택 조작 통일 (2026-11-14)

- 사용자가 스크롤/범위 선택 차이를 파악하기 어렵다는 피드백에 따라 두 모드 버튼과 전환 상태를 제거했습니다. 전체 보기·확대 보기 모두 한 번 눌러 개별 선택, 길게 누르고 끌어 사각형 선택으로 통일합니다. 확대 화면에서 일반 밀기는 화면만 이동합니다.
- 행·열 번호 선택, 같은 조건 선택, 좌표 이동, 고정 헤더, 범위 선택 중 가장자리 자동 스크롤을 유지합니다. 선택 시작점은 길게 누른 well이며 기존 선택 위치를 새 드래그 기준으로 사용하지 않습니다. 손을 떼거나 취소하면 자동 스크롤을 종료합니다.
- 선택·탐색만으로 기록을 저장하거나 이력을 만들지 않습니다. 저장·백업 형식 변경은 없으며 장갑·실제 기기 길게 누르기 감도는 수동 QA로 확인합니다. 파종 부피 기록·배지 일괄 계산·측정 회차의 후속 우선순위는 유지합니다.
