# PlateNote 피펫팅 계획 계산 기준

PlateNote는 각 목표 농도의 master mix를 하나의 stock에서 만드는 **직접 희석**과, 높은 농도에서 낮은 농도로 순서대로 옮기는 **연속 희석** 계획을 제공합니다.

## 입력값

- Stock 농도
- 목표 농도 series
- Well당 최종 부피
- 반복 well 수
- 여유분 비율
- 농도 단위 (stock과 목표 농도가 공유)

Plate 분주 부피는 현재 µL 기준으로 계산하고 저장합니다.

Stock 농도와 목표 농도는 같은 농도 단위를 사용해야 합니다. 목표 농도는 stock 농도보다 높을 수 없습니다.

## Master mix 총량

각 농도별 준비량은 다음과 같이 계산합니다.

`total volume = volume per well × replicate count × (1 + overage percent / 100)`

예를 들어 well당 100 µL, 2반복, 여유분 10%이면 각 농도별로 220 µL를 준비합니다.

## Stock과 희석액

C1V1 = C2V2 관계를 사용합니다.

`stock volume = total volume × target concentration / stock concentration`

`diluent volume = total volume - stock volume`

0 농도 control은 stock 0, 희석액 전체 부피로 표시합니다.

## 연속 희석과 단계별 잔여량

연속 희석은 마지막 양성 농도부터 역순으로 계산하여, 각 농도에서 Plate에 분주할 master mix를 남긴 뒤에도 다음 농도를 만들 수 있게 준비량을 확보합니다.

- 각 단계의 `Plate 분주량`은 well당 부피 × 반복 수 × 여유분입니다.
- 다음 단계에 필요한 전체 부피를 기준으로 C1V1 = C2V2를 적용해 transfer 부피를 계산합니다.
- 현재 단계의 총 준비량은 Plate 분주량과 다음 단계 transfer 부피의 합입니다.
- 0 농도 control은 이전 농도 용액을 옮기지 않고 희석액만 별도로 준비합니다.
- 연속 희석은 목표 농도가 높은 농도에서 낮은 농도 순서일 때만 계산합니다.

## 실험 전 확인사항

- 1 µL 미만의 stock 분주가 계산되면 앱에서 경고합니다. 사용하는 피펫의 검증 범위를 확인하고 필요하면 중간 희석액을 준비해야 합니다.
- 앱은 stock과 목표 농도의 단위 환산을 자동으로 수행하지 않습니다. 두 값에 동일한 단위를 사용해야 합니다.
- 계산값은 제조 계획 보조용입니다. 실제 실험에서는 용액 밀도, 용매 허용 농도, dead volume, 장비 정확도와 연구실 SOP를 함께 확인해야 합니다.
- 연속 희석 중 혼합 손실, tube dead volume과 tip 내 잔류량은 자동 보정하지 않으므로 연구실 SOP에 따라 추가 여유분을 설정해야 합니다.


## 기존 배지에 추가·일부 교체·전체 교체 (2026-11-01)

well 또는 범위를 선택하고 `추가·교체 계산`을 엽니다. 직접/연속 희석은 새 용액을 만드는 기존 기능이며, 이 계산은 이미 well에 있는 배지에 용액을 넣는 경우를 다룹니다.

모든 부피는 well당 µL이며 기존 시약과 추가 용액은 같은 시약·같은 농도 단위여야 합니다. 용매는 같은 이름의 한 종류만 계산합니다. 기존 기록이 모두 같으면 초기값을 채우고, 다른 값이나 미기록 값은 빈칸으로 두어 직접 확인합니다. 미기록 농도·용매 비율을 0으로 추정하지 않습니다. 기존 부피/농도/용매 기록과 다른 입력으로 추가·일부 교체 결과를 적용할 수 없습니다. 다른 조건을 선택하거나 기존 기록을 먼저 확인해야 합니다.

기존 부피 `V0`, 제거 부피 `Vr`, 추가 부피 `Va`, 기존 농도 `C0`, 추가 농도 `Ca`, 기존/추가 용매 비율 `P0`/`Pa`에 대해:

- 추가: `Vr = 0`
- 일부 교체: `0 < Vr < V0`; 배지가 균일하게 혼합된 상태에서 먼저 제거
- 전체 교체: 기존 배지 전량 제거, 잔류액 0; 기존 농도·용매는 최종 값에 미포함
- 잔류 부피: `Vremain = V0 - Vr` (전체 교체는 0)
- 최종 부피: `Vfinal = Vremain + Va`
- 최종 농도: `Cfinal = C0 × (Vremain / Vfinal) + Ca × (Va / Vfinal)`
- 최종 용매 비율(% v/v): `Pfinal = P0 × (Vremain / Vfinal) + Pa × (Va / Vfinal)`

| 사례 | 입력 | 결과 |
| --- | --- | --- |
| 추가 | 기존 100 µL·5 µM·용매 0.2%, 추가 20 µL·50 µM·용매 2% | 120 µL·12.5 µM·용매 0.5% |
| 일부 교체 | 기존 100 µL·10 µM·용매 0.1%에서 40 µL 제거, 시약/용매 없는 배지 20 µL 추가 | 80 µL·7.5 µM·용매 0.075% |
| 전체 교체 | 기존 전량 제거, 75 µL·2 µM·용매 0.2% 추가 | 75 µL·2 µM·용매 0.2% |

`최종 조건 계산`은 미리보기만 표시합니다. 최종 배지/버퍼 이름과 모든 선택 well에 같은 입력·시약/용매가 해당하는지 확인한 뒤 `선택 well에 최종 조건 기록`으로 적용합니다. 계산 후 입력을 바꾸면 이전 결과와 확인 상태가 해제되어 다시 계산해야 합니다.

기록 시 농도·농도 단위·부피·배지·용매를 갱신합니다. 기존 세포 파종 조건·실험군·역할·측정값·분석 제외 상태는 보존합니다. 측정 후 변경은 기존 정정 사유/이력 절차를 거칩니다. 입력·제거·잔류·최종 값과 대상 좌표를 최근 변경 이력에 남기고 기존 Plate 스냅샷을 보존합니다. 실제 분주/교체 완료나 실행 단계를 자동으로 기록하지 않습니다.

부피 합산과 균일 혼합을 가정하며 배지 성분 혼합, 세포 손실, 흡수/분해/증발, 장비 dead volume, 용매 허용 한계·well 용량, 단위 환산은 자동 계산하지 않습니다. 최종 배지 이름을 직접 확인하고 장비·연구실 조건에 맞는 값을 사용해야 합니다. 1 µL 미만 분주/제거에는 경고합니다. 전체 준비량은 여유분 없이 추가 부피 × 선택 well 수이며, 표시값 반올림과 별개로 저장에는 계산값을 유지합니다.
